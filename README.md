An entry for make.fun's [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty ($5 in USDC): a program that writes a single dad joke — a mirror that reflects on honest feedback, then tells you to face the facts.

## What it does

`main.py` (Python 3.13, standard library only) writes one dad joke to `/output/entry.txt`. The output is deterministic: every run writes the same 116 characters, well within the 1–200 character limit.

> I asked my mirror for honest feedback. It reflected on it for a moment, then said I really needed to face the facts.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
